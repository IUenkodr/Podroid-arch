What makes this fork different?\n\nUnlike the original Podroid which uses Alpine Linux, this fork implements a **full Arch Linux ARM64 VM**. You get the power of the Arch User Repository (AUR) and a rolling-release distribution directly on your Android device.\n\n## What you get\n\n- **Arch Linux ARM64** - A complete, rolling-release VM.\n- **Podman, Docker and LXC** - pre-installed, ready the moment it boots.\n- **A real VM** - Custom kernel via QEMU, or hardware-accelerated AVF on supported pKVM devices.\n- **In-app terminal** - full xterm-256color, 122 color themes, 13 fonts, live resize.\n- **X11 desktop** - run GUI Linux apps in a built-in viewer with touch, keyboard, mouse and audio.\n- **USB passthrough**, **SSH**, **port forwarding** and a **guest-to-Android bridge**.\n- **Container backup**, a **live VM/device status view** and **Downloads-folder sharing** with the guest.\n- **English and ??**, no root, any arm64 device on Android 8+.\n\n## Quick start\n\n1. [Download the APK](https://github.com/IUenkodr/Podroid-arch/releases/latest) and install it.\n2. Tap **Start VM**, wait for **Ready!**, open the terminal.\n\n```sh\n# rootless containers, straight away\npodman run --rm archlinux echo "hello from a container"\ndocker run -d -p 8080:80 nginx\n\n# expose that container to your phone and LAN, right from the VM shell\npodroid-forward add 8080 8080 tcp\ncurl http://<phone-ip>:8080\npodroid-forward clean\n\n# SSH in from your laptop\nssh root@<phone-ip> -p 9922        # password: podroid\n```\n\n## Build\n\n### Automated Builds\nThis fork is configured to build APKs automatically using GitHub Actions. Check the **Actions** tab for the latest successful build artifacts.\n\n### Manual Build\n```sh\ngit clone https://github.com/IUenkodr/Podroid-arch.git\ncd Podroid-arch\n./build-all.sh all     # kernel, rootfs, QEMU and APK (needs Docker + Android SDK/NDK)\n```\n\n## Credits\n\n| | |\n|---|---|\n| [QEMU](https://www.qemu.org)                   | Machine emulation |\n| [Termux](https://github.com/termux/termux-app) | Terminal emulator engine |\n| [Arch Linux ARM](https://archlinuxarm.org)    | The guest distribution |\n| [ExTV/Podroid](https://github.com/ExTV/Podroid) | The original framework |\n\n## License\n\n[GPLv2](LICENSE).
